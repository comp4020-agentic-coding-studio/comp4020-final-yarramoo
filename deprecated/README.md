# Deprecated: Makers Wanted

This is the "Makers Wanted" social site from crit 8: the old app (`src/`, `public/`, `data/`, its specs and seed scripts), kept here for reference.

It is not built, run or tested. `tsconfig.json` and vitest both ignore this directory, and the Dockerfile does not copy it.

The full working version lives on the `social-builder` branch and the `crit-8` tag.
