# Crit 8 reflection

1. What was the breakthrough that moved the work forward?
Committing to the workflow of one main Opus agent dispatching work to Sonnet/Haiku subagents made making this page a piece of cake. No compactions, cheap tokens, and sophisticated feature suggestions and understanding during planning back and forth. Right at the beginning I added the dispatch rules to the `CLAUDE.md` markdown, along with budget allocations per delegation. 

Something new that I did was add a `FUTURE.md` file; I added a rule to the harness for the agent to add in notes to that file for future ideas or features that came up during development or ideating. Knowing that this project will last for multiple crits, it made sense to keep some ideas in the back for later. 

2. What did this work change about who I want to be as a software developer?
This was the first thing I made that was intentionally a social platform. Seeing how easy they are, I kind of want to try making small-scale apps for friends/neighbours.
