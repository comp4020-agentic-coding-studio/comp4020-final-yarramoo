## Design note
Pixel art means: no radius, 2 px "art pixels" for borders and shadows, hard bevels, one pixel font at multiples of
11 px, the logo at integer scale. The backdrop is the game itself, so panels are near-opaque night-purple slabs
(`--mn-panel` at 92%) and never rely on blur. Colour comes from the materials: sand is the primary action, lava is
danger/PvP (Deathmatch), moss is co-op (Survival), water is joining. Screens: title (logo, New game, Join game,
players live, death log), types, settings (themed per type), join (list + code), share (private room link).

## Architectural decisions for review
1. **Mobs: option (a), a real local Caves sim with one local explorer.** Config `{terrain 0, size 1, avatars 1,
   damage 0, brushes 1, round 0, enemies 1}` (`client/menu/backdrop-config.ts`), passes `decode`: **no sim or ABI
   change**. The explorer is player 1, Joined locally and moved by the game's own controller (Pos), because enemies
   and chunks only step near an active, alive player. Seed 220 and three camera windows are constants found offline
   (`tools/menu-vignettes.ts`), so nothing read from the sim chooses an input (invariant 9). Cost: a generator change
   can empty the windows; `tests/net/menu-backdrop.test.ts` fails if a window loses its mobs (not if it loses its
   surface). Alternatives rejected: (b) a spawn input (ABI change, needs sign-off), (c) decorative sprites (fake state).
2. **Size M for the backdrop**, because local mode treats only `width() > 512` as a game world. Cost: 1024x768 of
   memory and a 100-330 ms generation every ~75 s (world restart after the three vignettes).
3. **`goto` worker message** (local sim only, teleports the local controller; the sim hears an ordinary Pos).
   General rather than dev-only; easy to delete.
4. **Endpoint: `GET /api/live`** `{players, rooms, deaths[{victim, killer, self, cause, bag, mode, at}]}`, a pure
   `server/live.ts` (ring of 20, 2 s cache with an injected clock), filled in `onDeathResolved` for public rooms only,
   plain names; in memory (a restart empties the log). A separate endpoint rather than widening `/api/rooms`, so the
   title polls one small cached object and the room list stays as it was.
5. **Routing: hash routes** (`""`, `#new`, `#new/<type>`, `#join`, `#share/<CODE>`) with a depth counter in
   `history.state`, so Back never leaves the site and no server route is added. Cost: a hand-edited hash can leave the
   depth off by one (Back then sets the parent hash instead of `history.back()`).
6. **Font and licence**: Pixelify Sans, SIL OFL 1.1, self-hosted WOFF subset (14.8 KB) with the licence beside it;
   sizes on its 11 px grid. **Logo**: hand-drawn pixel wordmark from a committed script (image generation is disabled
   for this course key: HTTP 403).
7. **File split**: `client/menu.ts` (shell, name sheet), `client/menu/{router,screens,live,backdrop-config}.ts`,
   `client/menu.css` (tokens, primitives, screens, backdrop host). `screens.ts` is ~530 lines and could split per screen.
8. **Visible settings**: size S/M/L, max players, Deathmatch respawn (1-10 s stepper), Public/Private; every config
   field remains under Advanced. The Deathmatch preset lives in `screens.ts`, not `shared/room.ts`.
